Reusable Components Library 🛠️



Welcome to the Enterprise Reusable Components repository. This centralized library houses production-ready accelerators designed to standardize automation, enforce strict error contracts, and accelerate delivery across multiple technology stacks.



🌿 Repository Structure (Branches)



To keep technology stacks isolated and maintain clean version control, this repository uses a branch-based architecture.



Please switch to the relevant branch using the dropdown above to view the source code and documentation for each platform:



uipath: Contains enterprise-grade workflows, including the PDF Splitting Engine, Microsoft Graph \& SharePoint Toolkit, and the Config-Driven Framework.



powerapps: Contains Canvas Apps, Power Automate flows, and AI Agent UI integrations.



automation-anywhere: Contains enterprise task bots and reusable A360 logic.



agentic-ai: Contains Python scripts, multi-agent frameworks (LangGraph, CrewAI), and LLM integrations.



⚙️ Engineering Standards



All components across our branches adhere to strict enterprise guidelines:



Dynamic Configuration: No hardcoded credentials or local environment paths.



Strict Error Contracts: Clear separation between business rule exceptions and system exceptions for reliable unattended execution.



Scalability: Modular architecture designed to plug seamlessly into high-volume enterprise frameworks.
